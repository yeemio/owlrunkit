# Corresponding Source

OwlRunKit is distributed under `GPL-3.0-or-later`. This repository is its public
corresponding-source, documentation, issue, release, and trust surface:

https://github.com/yeemio/owlrunkit

Day-to-day development happens in a private source repository. For every
GPL-covered npm release, the exact public tag must contain the preferred form
for modification: JavaScript source, package metadata, public contracts,
bundled integration resources, and the scripts needed to inspect the release.

The npm tarball also contains the complete, unminified JavaScript source for the
published runtime and read-only verifier. It contains no generated minified
binary as a substitute for source.

Release identity is the tuple of npm version, shasum, integrity, canonical
tarball URL, and matching public source tag. Local directories, `file:`
dependencies, local tarballs, Git URLs, workspace links, and mutable dist-tags
are not formal cross-project adoption evidence.

For `owlrunkit@0.24.1`, use tag `v0.24.1` in this repository.
